# 个人展示网站（Portfolio）

深色「赛博朋克·霓虹」风格的个人展示网站，纯静态，含霓虹粒子星空、故障字效、扫描线。

## 预览

直接双击 `index.html` 即可在浏览器打开。

## 部署

推送到 GitHub 后，仓库 Settings → Pages → 选择 `main` 分支根目录即可获得域名。

## 修改内容

- 个人信息 / 技能 / 项目 / 博客：编辑 `data.js`（或用管理后台在线改，见 `portfolio-admin` 仓库）
- 主题色 / 风格：编辑 `css/style.css` 顶部 `:root` 变量
- 粒子数量 / 动画：编辑 `js/main.js` 顶部配置
